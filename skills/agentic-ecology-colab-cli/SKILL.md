# Colab CLI Skill

This skill provides instructions for using the external `google-colab-cli` to
offload heavy computation (such as model training or dataset embedding
generation) to a remote Google Colab VM with GPU/TPU accelerators.

## Workflow Overview

Follow these sequential steps when offloading workloads to Google Colab:

1.  **Verify CLI Installation:** Verify that the Colab CLI is available in the
    environment. If it is missing, install it (see the Installation section in
    the technical reference).
2.  **Authorize CLI:** Check active sessions to verify credentials. If the CLI
    is unauthenticated, retrieve the OAuth link generated by the CLI, present it
    to the user, and wait for the user to provide the authorization code to
    complete login.
3.  **Provision Remote Session:** Create a new remote session with a unique
    name. Select a GPU accelerator if required for the workload, or default to
    CPU.
4.  **Mount Google Drive:** Trigger the Drive mounting command for the session.
    *Note: If the session is headless/remote, monitor the logs for the OAuth
    URL, display it to the user, and wait for them to authorize.*
5.  **Install Dependencies:** Install all necessary Python libraries or
    `requirements.txt` packages on the remote VM.
6.  **Execute Processing Script:** Execute the Python script locally from your
    workspace onto the remote VM.
7.  **Clean Up VM Resources:** Immediately stop the session after execution
    completes to release resources and avoid compute unit charges.
